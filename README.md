# Github Search

A React + TypeScript application that allows you to search GitHub users and view their profiles, repositories, and stats. Built with GraphQL (Apollo Client), Tailwind CSS, Shadcn UI, and custom styling for a modern, responsive experience.
🚀 Features
- Search GitHub users via GitHub API (GraphQL).
- Display user profile, repositories, and language stats.
- Interactive charts for commits, forks, stars, and popular languages.
- Component‑based architecture for maintainability.
- Theming support with custom styling and Shadcn UI.
- Responsive design with Tailwind CSS.

🛠️ Tech Stack
- Frontend: React + TypeScript
- State/Data: Apollo Client (GraphQL), React Query
- Styling: Tailwind CSS, Shadcn UI, custom CSS
- Architecture: Component‑based, modular folder structure
